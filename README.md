# Free Finance
 
 Esse projeto tem como finalidade produzir o aplicativo Free Finance, que tem como objetivo ajudar o usuário a controlar suas finanças pessoais, permitindo o registro de receitas e despesas, além de fornecer relatórios e gráficos para melhor visualização do fluxo financeiro.

 # Como utilizar o Free Finance

    1. Faça o download do aplicativo Free Finance na loja de aplicativos do seu dispositivo.
    2. Abra o aplicativo e crie uma conta ou faça login com uma conta existente.
    3. Após o login, você poderá adicionar suas receitas e despesas, categorizando-as de acordo com suas necessidades.
